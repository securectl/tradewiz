Setup Instructions
BloFin (Crypto Trading)
  1. Sign up at blofin.com
  2. Go to Account → API Management (direct link)
  3. Create API key with "Trade" permission
  4. Copy API Key, Secret, and Passphrase into the fields above
  5. Enable Demo Trading for paper trading
Alpaca (Stock Trading)
  1. Sign up at alpaca.markets
  2. Go to Paper Trading → API Keys (dashboard)
  3. Generate new key
  4. Copy API Key and Secret Key into the fields above
Webull (Stock Trading)
  1. You need a funded Webull brokerage account
  2. Apply for API access at developer.webull.com (1-2 day approval)
  3. After approval, copy your App Key from the developer dashboard
  4. Generate an App Secret (expires in 1-7 days, regenerate as needed)
  5. Account ID is auto-detected when you Test Connection — leave it blank

Note: App Secret expires (max 7 days). Regenerate at developer.webull.com when it stops working.
