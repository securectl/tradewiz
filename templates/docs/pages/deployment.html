Deployment

Deploy AI Stock Analyst to Railway with PostgreSQL, Google OAuth, and a custom domain.

Railway Setup

1. Create a Railway Project

  1. Go to railway.app and sign in
  2. Click New Project
  3. Select Deploy from GitHub repo
  4. Connect your repository

2. Add PostgreSQL

  1. In your Railway project, click New Service → Database → PostgreSQL
  2. Railway will provision a PostgreSQL instance
  3. Copy the DATABASE_URL from the PostgreSQL service's Connect tab
  4. Add it to your app service's environment variables
Tip

Railway can automatically inject DATABASE_URL using variable references: {% raw %}${{Postgres.DATABASE_URL}}{% endraw %}. This is the recommended approach.

3. Configure Environment Variables

Set the following in your Railway app service's Variables tab:

VariableRequiredNotes
DATABASE_URLYesReference from Postgres plugin
SECRET_KEYYesRandom string, at least 32 chars
ENCRYPTION_KEYNoAuto-generated on first run
GOOGLE_CLIENT_IDYesFrom Google Cloud Console
GOOGLE_CLIENT_SECRETYesFrom Google Cloud Console
ADMIN_EMAILYesYour Google account email
OPENROUTER_API_KEYRecommendedRequired for AI features

4. Deploy

Railway auto-deploys on push to your main branch. The app detects DATABASE_URL and uses PostgreSQL automatically. The migrations.py script runs on startup to create/update tables.

Google Cloud Console Setup

1. Create OAuth Credentials

  1. Go to Google Cloud Console
  2. Select or create a project
  3. Navigate to APIs & Services → Credentials
  4. Click Create Credentials → OAuth client ID
  5. Application type: Web application

2. Configure Redirect URIs

Add the following authorized redirect URI:

https://your-app.up.railway.app/auth/callback

If you have a custom domain:

https://your-domain.com/auth/callback
Important

The redirect URI must exactly match what Google sends back. Include https:// and the exact path /auth/callback. No trailing slash.

3. Configure Consent Screen

  1. Go to APIs & Services → OAuth consent screen
  2. User type: External (or Internal for Google Workspace)
  3. Add scopes: email, profile, openid
  4. Add test users if in testing mode
  5. Publish the app when ready for production use

Custom Domain

To use a custom domain on Railway:

  1. In your Railway project, go to your app service's Settings
  2. Under Networking → Custom Domain, add your domain
  3. Configure DNS: add the CNAME record Railway provides
  4. Update your Google OAuth redirect URI to use the new domain
  5. Railway handles SSL/TLS automatically

Troubleshooting

App crashes on startup

  • Check Railway logs for Python import errors — a missing dependency in requirements.txt
  • Ensure DATABASE_URL is correctly set and the PostgreSQL service is running

Google OAuth redirect error

  • Verify the redirect URI in Google Cloud Console exactly matches your deployed URL + /auth/callback
  • Ensure the OAuth consent screen is published (not in testing mode with restricted users)

Database migration issues

  • migrations.py runs automatically on startup and handles both fresh installs and upgrades
  • If you see table errors, check Railway's PostgreSQL version compatibility
