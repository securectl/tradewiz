AI Stock Analyst

An AI-powered stock and crypto analysis platform with automated trading bots, multi-model AI validation, and comprehensive portfolio tracking.

What is this?

AI Stock Analyst combines technical analysis, AI-powered validation from multiple LLMs, and automated trading into a single self-hosted platform. Analyze stocks, scan for breakout patterns, and run paper-trading bots — all from a dark TradingView-inspired interface.

Key Features

Stock Analysis
Technical indicators, breakout detection, and AI-powered analysis with support/resistance levels.
AI Validation
Multi-model consensus from Claude, Gemini, and DeepSeek with confidence scoring.
Crypto Trading Bot
Automated crypto trading on BloFin with 7 strategies, risk gates, and circuit breakers.
Stock Trading Bot
Automated stock trading via Alpaca or Webull with market-hours awareness.
Screener & Scanner
Qullamaggie breakout scanner and AI-powered stock screener with sector analysis.
Trade Tracker
Journal your trades, set weekly goals, and track P&L across your portfolio.

Quick Start

  1. Clone and install — pip install -r requirements.txt
  2. Configure — Copy .env.example to .env and set your keys
  3. Run — python migrations.py && python app.py
  4. Open — Visit http://localhost:5001

See the Getting Started guide for detailed setup instructions.
