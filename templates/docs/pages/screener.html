Qullamaggie Breakout Scanner

The Qullamaggie scanner identifies stocks exhibiting breakout patterns based on the methodology of Kristjan Qullamaggie and Mark Minervini. It scans a category of tickers and ranks them by breakout quality.

What It Looks For

  • Uptrend confirmation — Price above SMA 50 and SMA 200
  • Consolidation — Tight price range with declining volume
  • Breakout — Price breaking above consolidation with expanding volume
  • Momentum — RSI and MACD alignment confirming the move

How to Use

  1. Go to the Breakout Scanner tab
  2. Select a ticker category (e.g., Tech, Growth, Crypto)
  3. Click Scan
  4. Results are ranked by breakout quality with technical details for each ticker

AI Stock Screener

The AI screener uses LLM intelligence to find stocks matching specific criteria. Unlike the technical scanner, the AI screener can understand complex, qualitative criteria.

How to Use

  1. Go to the Screener tab
  2. Select a category or enter custom screening criteria
  3. Set optional filters (sector, price range)
  4. Click Screen
  5. The AI returns ranked results with reasoning for each pick

The screener uses the LLM_SCREENER model (default: Gemini Flash) for fast, cost-efficient screening.

Hot Sectors

The hot sectors feature ranks market sectors by recent performance over a configurable time period. This helps identify where market momentum is concentrated.

Access via the Screener tab or the API: GET /api/screener/hot-sectors?period=1w

API Endpoints

POST /api/qullamaggie login_required
Run Qullamaggie breakout scan on a ticker category.
POST /api/screener login_required
Run AI-powered stock screener by category, sector, or price range.
GET /api/screener/hot-sectors login_required
Get hot sectors ranked by performance for a given period.
