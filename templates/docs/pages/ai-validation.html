AI Validation

Multi-model consensus system using Claude, Gemini, and DeepSeek for trade signal validation.

Overview

AI Validation uses multiple LLM models to independently assess trade signals and reach a consensus. This reduces false signals by requiring agreement from diverse AI perspectives.

Validators

Gate 1: Ollama (Local)

Fast local model for initial screening. Runs on your machine for zero-cost, low-latency validation.

  • RSI direction alignment
  • MACD histogram strength and direction
  • Historical win rate (flags if < 40%)
  • Confluence count (needs 2–3+ indicators aligned)
  • Outputs: approve/reject, confidence (0–1), reasoning
Ollama Setup

Install Ollama, then run ollama pull llama3.1:8b. The validator automatically falls back to OpenRouter-only if Ollama is unavailable.

Gate 2a: Sentiment Validator (OpenRouter)

Cloud-based model for momentum and confluence assessment.

  • Momentum direction and strength
  • Multi-indicator confluence assessment
  • Historical performance context
  • Market narrative and sector rotation
  • Uses LLM_BOT_SENTIMENT model (default: Gemini Flash)

Gate 2b: Risk Validator (OpenRouter)

Cloud-based model focused on risk assessment and false signal detection.

  • Risk score (0–100, reject if > 60)
  • False signal probability (0–1, reject if > 0.5)
  • Risk/reward ratio assessment
  • Historical win rate impact
  • Uses LLM_BOT_RISK model (default: DeepSeek)

Voting Rules

ScenarioRequirement
All 3 validators available2 of 3 must approve (majority vote)
Ollama unavailable2 of 2 OpenRouter models must agree
One OpenRouter fails2 of 2 remaining must agree
No validators availableAuto-approve (paper trading safety net)

Confidence Scoring

Each validator returns a confidence score (0–1). The final confidence is the average of all approving validators. This score is displayed in the trade details and used for logging purposes.

Performance History

Validators receive the last 7 days of closed trades as context, including:

  • Total trades and win rate
  • Average and total P&L
  • Win rate and average P&L per strategy
  • Win rate and average P&L per coin/stock

This helps validators make better decisions by considering recent performance patterns.

Configuring Validators

You can customize which models are used for validation:

# In .env
LLM_BOT_SENTIMENT=google/gemini-2.5-flash
LLM_BOT_RISK=deepseek/deepseek-chat-v3-0324
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b

Admins can also change models at runtime via the Admin tab without restarting.

User-Facing Validation

In addition to bot trade validation, users can manually validate any stock analysis result by clicking Validate with AI. This uses the LLM_RESEARCH model for a comprehensive assessment including:

  • Setup quality rating
  • Risk/reward analysis
  • Entry, stop-loss, and target recommendations
  • Confidence score and reasoning
