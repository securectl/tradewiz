API Reference

All 66 API endpoints grouped by category.

Authentication

All endpoints require authentication unless noted. Auth is session-based (cookie). Endpoints return JSON. Unauthorized requests receive 401; insufficient roles receive 403.

Auth

Authentication endpoints. No login required.

GET /auth/login public
Render the login page. Shows dev login form if Google OAuth not configured.
GET /auth/google public
Redirect to Google OAuth authorization.
GET /auth/callback public
Google OAuth callback. Upserts user, applies invite roles, logs in.
POST /auth/dev-login public
Dev-only login bypass. Disabled when GOOGLE_CLIENT_ID is set. Body: {"email": "..."}
GET /auth/logout public
Log out and redirect to login page.

Core

GET /api/me login_required
Get current user info: id, email, name, roles.
GET /api/ai-status public
Check if OpenRouter API key is configured.

Analysis

POST /api/analyze login_required
Run technical analysis on a ticker. Body: {"ticker": "AAPL"}. Saves result to search history.
POST /api/validate login_required
Run AI validation on a completed analysis. Body: analysis result JSON.
POST /api/predict login_required
Run AI 12-month investment prediction. Body: {"ticker": "AAPL"}.

Search History

GET /api/history login_required
Get user's search history (last 50 results).
GET /api/history/<id> login_required
Get the full result JSON for a specific search.
DELETE /api/history/<id> login_required
Delete a specific search result.

Screener

POST /api/screener login_required
Run AI-powered stock screener by category/sector/price range.
POST /api/qullamaggie login_required
Run Qullamaggie breakout pattern scan on a ticker category.
GET /api/screener/hot-sectors login_required
Get hot sectors ranked by performance. Query: ?period=1w.

Journal / Tracker

GET /api/journal login_required
List journal entries. Query: ?ticker=AAPL&page=1.
POST /api/journal login_required
Add journal entry. Body: {"ticker", "action", "quantity", "price", "notes"}.
DELETE /api/journal/<id> login_required
Delete a journal entry and reverse P&L.
GET /api/goals login_required
Get weekly/monthly P&L goals, balances, and progress.
POST /api/goals login_required
Update weekly target. Body: {"weekly_target": 100}.
POST /api/goals/balance login_required
Update account balance. Body: {"balance": 10000}.

Service Status

Get status of all monitored services with uptime %.
GET /api/status/uptime/<service> login_required
Get 90-day day-by-day uptime data for a single service.
GET /api/status/incidents login_required
