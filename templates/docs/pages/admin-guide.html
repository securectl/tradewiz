Admin Guide

User management, invites, role assignment, and system configuration.

Accessing the Admin Panel

The Admin tab is only visible to users with the admin role. You get admin access by:

  • Setting ADMIN_EMAIL to your email in .env
  • Being assigned admin by another admin
  • Using dev login mode (auto-grants admin)

User Management

Viewing Users

The Admin panel shows all registered users with their email, name, roles, and last login date.

Assigning Roles

To change a user's role:

  1. Find the user in the Admin panel
  2. Click the role button to add or remove a role
  3. Available roles: user, trader, admin
Role Hierarchy

admin inherits all trader permissions. trader inherits all user permissions. You only need to assign the highest role needed.

Invite System

Pre-authorize users before they sign up to give them specific roles on first login.

Creating an Invite

  1. In the Admin panel, enter the user's email address
  2. Select the role to grant (user, trader, or admin)
  3. Click Invite

When the invited user logs in via Google OAuth with that email, the role is automatically applied. If the user already exists, their role is updated.

Managing Invites

  • View all invites — Listed in the Admin panel with email, role, and creation date
  • Update an invite — Re-invite the same email with a different role (upserts)
  • Delete an invite — Remove a pending invite before the user logs in

System LLM Configuration

Admins can update LLM model settings at runtime without restarting the server:

  1. Go to the Admin panel
  2. Find the LLM Configuration section
  3. Update any of the following:
    • OPENROUTER_API_KEY — API key for all AI features
    • LLM_RESEARCH — Model for deep analysis
    • LLM_RESEARCH_FAST — Fast analysis model
    • LLM_PATTERN — Pattern recognition model
    • LLM_PREDICTION — Prediction model
    • LLM_SCREENER — Screener model
    • LLM_BOT_SENTIMENT — Bot sentiment model
    • LLM_BOT_RISK — Bot risk model
    • OLLAMA_URL — Local Ollama server URL
    • OLLAMA_MODEL — Local Ollama model
  4. Click Save — Changes take effect immediately
Tip

Hot-reloaded LLM settings are stored as environment variables for the running process. They persist until the server is restarted, at which point values from .env are used again.

API Endpoints

GET /api/admin/users admin_required
List all users with their roles.
POST /api/admin/users/<id>/role admin_required
Add or remove a role for a user.
GET /api/admin/invite admin_required
List all invites.
POST /api/admin/invite admin_required
Create or update an invite for an email with a role.
DELETE /api/admin/invite/<email> admin_required
Delete a pending invite.
GET /api/admin/config admin_required
Get current LLM/OpenRouter config (API key is masked).
POST /api/admin/config admin_required
Update LLM models and API keys. Changes take effect immediately.
