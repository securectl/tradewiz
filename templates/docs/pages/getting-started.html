Getting Started

Get AI Stock Analyst running locally in under 5 minutes.

Prerequisites

  • Python 3.11+ — Required runtime
  • pip — Python package manager
  • Git — To clone the repository
  • OpenRouter API key — For AI features (optional for basic analysis)

Installation

1. Clone the repository

git clone <your-repo-url>
cd ai_stock_analyst

2. Install dependencies

pip install -r requirements.txt

3. Create your environment file

cp .env.example .env

Edit .env with your settings. For local development, the minimum configuration is:

# Minimum .env for local dev
SECRET_KEY=any-random-string-here
ENCRYPTION_KEY=          # Auto-generated on first run
DATABASE_URL=            # Leave empty to use SQLite
Tip

When GOOGLE_CLIENT_ID is not set, the app automatically enables dev login mode — you can log in with any email, no Google OAuth needed.

4. Initialize the database and run

python migrations.py
python app.py

The app starts on http://localhost:5001.

First Login (Dev Mode)

  1. Open http://localhost:5001
  2. You'll see the dev login form (since Google OAuth is not configured)
  3. Enter any email address and click Login
  4. You'll be logged in with admin + trader roles automatically

Your First Analysis

  1. On the Analyzer tab, type a ticker symbol (e.g., AAPL)
  2. Click Analyze — this runs technical analysis using price data
  3. View the results: chart, indicators, signal, and AI analysis
  4. If you have an OPENROUTER_API_KEY, click Validate with AI for multi-model consensus

Optional: Enable AI Features

To enable AI-powered analysis and validation, add your OpenRouter API key:

OPENROUTER_API_KEY=sk-or-v1-your-key-here

This unlocks:

  • AI stock analysis and predictions
  • Multi-model validation (Claude, Gemini, DeepSeek)
  • AI-powered stock screener
  • Bot trade validation via LLM consensus

See Configuration for all available environment variables.
