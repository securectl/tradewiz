Analyzer

The primary analysis tab — interactive charting, breakout pattern detection, AI validation, and 12-month investment predictions.

Overview

The Analyzer is the main feature of AI Stock Analyst. Enter any stock or crypto ticker to get a full technical analysis with interactive candlestick charts, detected breakout patterns, a calculated trade plan, and optional AI-powered validation and long-term predictions.

Chart Toolbar

The interactive chart includes overlay toggles:

  • Moving Averages: 9 EMA, 20 SMA, 50 SMA, 100 SMA, 200 SMA
  • Volume: Toggle volume bars on/off
  • Pattern Overlays: Trendlines, swing highs/lows, breakout levels, and price targets are drawn automatically when a pattern is detected

Validate with AI

Runs three specialized LLMs in parallel via OpenRouter to rigorously vet the current trade setup. Each model focuses on a different angle, and their outputs are synthesized through risk gates into a final verdict.

Requirement

An OpenRouter API key must be configured (via .env or Admin → System Config). The "Validate with AI" button only appears after a successful analysis.

Model 1: Research & Fundamentals

Focuses on why the trade could fail. Analyzes company fundamentals, sector context, catalysts, and red flags with a risk-first approach.

Default model: anthropic/claude-sonnet-4-6 (or google/gemini-2.5-flash in fast mode)

View Full Prompt 
System: "You are a risk-first stock analyst. Capital preservation
is #1. Respond with ONLY valid JSON. No markdown, no code fences."

User: "Analyze {ticker} setup. Find reasons this trade could FAIL.
Never risk >5% account on any position.

{data_summary}

Respond with ONLY this JSON (replace values):
{
  "verdict": "BULLISH",
  "confidence": 75,
  "catalysts_bullish": ["catalyst1"],
  "catalysts_bearish": ["risk1"],
  "red_flags": ["flag1"],
  "earnings_risk": "assessment",
  "key_risk": "biggest single risk",
  "summary": "1-2 sentences, risk-first"
}"

Output fields:

  • verdict — BULLISH, BEARISH, or NEUTRAL
  • confidence — 0–100 score
  • catalysts_bullish / catalysts_bearish — Upside drivers and downside risks
  • red_flags — Critical concerns (3+ flags triggers a risk gate)
  • earnings_risk — Proximity to earnings and impact assessment
  • key_risk — Single biggest risk to the trade

Model 2: Pattern Validation

Validates or rejects the detected chart pattern. Specifically trained to catch false breakouts, which are the primary account killer for breakout traders.

Default model: google/gemini-2.5-pro-preview (always uses Pro for pattern accuracy)

View Full Prompt 
System: "You are a technical analyst. False breakouts destroy
accounts. Respond with ONLY valid JSON. No markdown, no code fences."

User: "Validate or reject this pattern for {ticker}. Be ruthless
— false breakouts destroy accounts.

{data_summary}

Respond with ONLY this JSON (replace values):
{
  "pattern_valid": true,
  "pattern_confidence": 75,
  "detected_pattern": "Symmetrical Triangle",
  "breakout_probability": 70,
  "false_breakout_risk": "MEDIUM",
  "false_breakout_reasons": ["reason1"],
  "support_resistance_key_levels": ["$100", "$95"],
  "optimal_entry": "price and condition",
  "invalidation_level": "$X",
  "summary": "1-2 sentences"
}"

Output fields:

  • pattern_valid — Whether the detected pattern is legitimate
  • pattern_confidence — 0–100 score (penalized by -30 if invalid)
  • breakout_probability — Likelihood of successful breakout
  • false_breakout_risk — LOW / MEDIUM / HIGH (HIGH triggers risk gate)
  • support_resistance_key_levels — Key price levels to watch
  • optimal_entry — Recommended entry price and conditions
  • invalidation_level — Price where the pattern breaks down

Risk Gates (Auto-AVOID)

Before computing the final verdict, the system checks four risk gates. If 2 or more gates trigger, the verdict is forced to AVOID regardless of model scores.

Risk GateTrigger Condition
Extreme risk scoreModel 3 risk_score ≥ 75
High false breakout riskModel 2 false_breakout_risk = "HIGH"
Pattern rejectedModel 2 pattern_valid = false
Multiple red flagsModel 1 red_flags count ≥ 3

Final Verdict Scoring

VerdictConditions
STRONG BUYAvg score ≥ 70 AND 2+ models bullish
BUYAvg score ≥ 55 AND 1+ bullish AND 0 avoid
WAITPrediction model says WAIT
NEUTRALMixed signals, no clear direction
AVOID2+ risk gates OR 2+ models warn OR avg score < 35

Run 12-Month Prediction

Runs three specialized LLMs in parallel to evaluate a stock as a long-term investment. Unlike "Validate with AI" (which analyzes short-term trade setups), this focuses on business fundamentals, financial health, and fair valuation for a 12-month holding period.

Data Source

The prediction uses fundamental data (P/E, margins, cash flow, debt, analyst targets, financial trends) rather than technical chart data. The "Run 12-Month Prediction" button appears after a successful analysis.

Risk Gates (Auto-PASS)

Critical financial risks that force the verdict to PASS:

Risk GateTrigger Condition
Low survival probabilityModel 2 survival_probability < 75%
High dilution riskModel 2 dilution_risk = "HIGH"

Either gate alone forces a PASS verdict.

Final Verdict Scoring

VerdictConditions
INVEST2+ models say INVEST AND avg score ≥ 60
HOLD1+ INVEST AND avg score ≥ 50, or mixed signals
PASSRisk gate triggered OR 2+ models say PASS OR avg score < 35

Supervisor Gate (Optional)

When LLM_SUPERVISOR is configured, a 4th LLM acts as a senior supervisor that reviews the consensus from the three primary models. It can veto the verdict if it finds critical issues the other models missed.

  • Only runs if the verdict is NOT already AVOID (setup) or PASS (prediction)
  • Override changes the verdict to AVOID or PASS and adds reasoning to risk flags
  • On error, gracefully degrades (no override applied)

Fast Mode

When fast mode is enabled (toggle in the UI or LLM_FAST_MODE=1), the research and health models switch to google/gemini-2.5-flash for faster, cheaper results. The pattern model always uses Gemini Pro for accuracy.

API Endpoints

EndpointMethodDescription
/api/validatePOSTRun AI validation on current analysis
/api/predictPOSTRun 12-month investment prediction

Both endpoints require authentication and are rate-limited (3 calls per source per time window).

Configuring Models

Override default models via environment variables or the Admin → System Config panel:

# In .env
LLM_RESEARCH=anthropic/claude-sonnet-4-6
LLM_RESEARCH_FAST=google/gemini-2.5-flash
LLM_PATTERN=google/gemini-2.5-pro-preview
LLM_PREDICTION=deepseek/deepseek-chat-v3-0324
LLM_SUPERVISOR=                                  # empty = disabled
LLM_MAX_TOKENS=2048
LLM_TEMPERATURE=0.2

Admins can change models at runtime via the Admin tab without restarting the application.
