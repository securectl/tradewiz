Stock Analysis

Technical indicators, breakout pattern detection, and AI-powered analysis.

How It Works

The analysis engine fetches price data for a given ticker, computes technical indicators, detects breakout patterns, and generates a signal with confidence scoring. If AI is configured, it provides narrative analysis with support/resistance levels.

RSI (Relative Strength Index)

14-period RSI measures momentum on a 0–100 scale.

  • Below 30 — Oversold (potential buy signal)
  • 30–70 — Neutral range
  • Above 70 — Overbought (potential sell signal)

MACD

MACD (12, 26, 9) detects momentum shifts through crossovers:

  • Bullish cross — MACD line crosses above signal line
  • Bearish cross — MACD line crosses below signal line
  • Histogram strength — Larger histogram = stronger momentum

ATR (Average True Range)

14-period ATR measures volatility. Used for stop-loss/take-profit placement and filtering out ranging markets (ATR < 0.3% of price = skip).

Bollinger Bands (20, 2)

Measures price position relative to statistical range:

  • BB Position 0% — Price at lower band (oversold)
  • BB Position 100% — Price at upper band (overbought)
  • BB Width — Narrow = potential breakout, Wide = high volatility

Volume

10-period volume moving average with relative volume ratio. A surge (>1.5x average) indicates strong participation.

Breakout Pattern Detection

The Qullamaggie breakout scanner looks for stocks that match the breakout criteria of Mark Minervini / Kristjan Qullamaggie style setups:

  • Price above SMA 50 and SMA 200 (confirmed uptrend)
  • Tight consolidation (low ATR relative to price)
  • Volume contraction then expansion
  • Price breaking above a consolidation range

AI-Powered Analysis

When an OpenRouter API key is configured, the analysis includes AI-generated narrative covering:

  • Overall market context and trend assessment
  • Key support and resistance levels
  • Pattern interpretation and confidence
  • Risk factors and trade recommendations

The AI uses the LLM_RESEARCH model (default: Claude Sonnet) for deep analysis. See AI Validation for the multi-model consensus system.
