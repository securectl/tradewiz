Configuration

All environment variables, LLM model settings, and API key configuration.

Environment Variables

All configuration is done via environment variables, typically in a .env file at the project root.

Core Settings

VariableDefaultDescription
SECRET_KEYdev-secret-key-change-meFlask session secret key. Change in production.
DATABASE_URLemptyPostgreSQL URL. If empty, uses local SQLite.
ENCRYPTION_KEYauto-generatedFernet key for encrypting stored API credentials. Auto-generated on first run and written to .env.

Authentication

VariableDefaultDescription
GOOGLE_CLIENT_IDemptyGoogle OAuth client ID. If not set, dev login mode is enabled.
GOOGLE_CLIENT_SECRETemptyGoogle OAuth client secret.
ADMIN_EMAILemptyEmail address that automatically receives admin role on login.

Security

Never commit your .env file to version control. API keys and secrets are encrypted at rest using the ENCRYPTION_KEY when stored per-user in the database.

LLM Model Configuration

The platform uses different LLM models for different tasks, each optimized for cost vs. quality. You can change any model by setting the corresponding environment variable to an OpenRouter model ID.

Model Roles

RoleUsed ForPriority
ResearchDeep stock analysis, comprehensive reportsQuality over speed
Research FastQuick analysis tasksSpeed over quality
PatternChart pattern recognition, breakout detectionVisual/spatial reasoning
Prediction12-month price predictionsReasoning capability
ScreenerStock screening and filteringSpeed + cost efficiency
Bot SentimentTrade signal sentiment validationSpeed (real-time)
Bot RiskTrade risk assessmentReasoning accuracy

Hot-Reloading Models

Admin users can update LLM models at runtime via the Admin tab without restarting the server. Changes take effect immediately for all subsequent AI calls.
